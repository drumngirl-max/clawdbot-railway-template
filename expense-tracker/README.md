# 💰 Expense Tracker — Telegram Mini App

Мини-приложение для Telegram, которое позволяет вести учёт личных расходов прямо с телефона. Открывается кнопкой в вашем боте, работает как обычное веб-приложение внутри Telegram, а данные хранятся в простом JSON-файле на сервере.

## Возможности

- ➕ Добавление расхода: сумма, категория, комментарий, дата
- 📊 Сводка за сегодня и за текущий месяц
- 📈 Разбивка расходов по категориям за месяц (наглядные полоски)
- 🗑 Удаление записей
- 🎨 Автоматическая подстройка под тему Telegram (светлая/тёмная)
- 🔐 Проверка подписи `initData` — доступ только у авторизованного пользователя Telegram
- 💾 Хранение в JSON-файле (без внешней БД)

## Как это устроено

```
Telegram (кнопка меню бота)
        │
        ▼
  Mini App (public/)  ──►  сервер Express (server.js)  ──►  data/expenses.json
```

- Фронтенд (`public/`) — чистые HTML/CSS/JS, без сборки и внешних зависимостей.
- Бэкенд (`server.js`) — Express: раздаёт статику и предоставляет API.
- Каждый запрос к API несёт заголовок `Authorization: tma <initData>`; сервер проверяет подпись Telegram, чтобы убедиться, кто пользователь.
- Данные лежат в `DATA_DIR/expenses.json`, сгруппированные по `userId`.

## Быстрый старт (локально)


## Настройка бота

1. Создайте бота у **@BotFather** (`/newbot`) и получите `BOT_TOKEN`.
2. Разверните приложение (см. ниже) и получите публичный `https://`-URL.
3. Привяжите Mini App к кнопке меню бота:

   ```bash
   BOT_TOKEN=123:ABC WEBAPP_URL=https://ваш-домен.up.railway.app npm run setup-bot
   ```

4. Откройте бота в Telegram и нажмите кнопку **💰 Расходы**.

## Деплой на Railway

1. Создайте новый сервис из этого репозитория (корень сервиса — папка `expense-tracker`).
2. Добавьте **Volume**, смонтированный на `/data`.
3. Задайте переменные окружения:
   - `BOT_TOKEN` — токен от BotFather (обязательно)
   - `DATA_DIR=/data` — чтобы данные переживали редеплои
   - `CURRENCY=₽` — символ валюты (необязательно)
4. Включите **Public Networking** — Railway выдаст домен и подставит `PORT`.
5. После деплоя запустите `setup-bot` с полученным `WEBAPP_URL`.

## Переменные окружения

| Переменная          | По умолчанию   | Назначение                                                       |
| ------------------- | -------------- | ---------------------------------------------------------------- |
| `BOT_TOKEN`         | —              | Токен бота; нужен для проверки подписи Telegram                   |
| `PORT`              | `8080`         | Порт HTTP-сервера (Railway задаёт сам)                           |
| `CURRENCY`          | `₽`            | Символ валюты в интерфейсе                                        |
| `DATA_DIR`          | `./data`       | Каталог для `expenses.json` (на Railway — путь волюма, напр. `/data`) |
| `MAX_AUTH_AGE`      | `86400`        | Максимальный возраст `initData` в секундах (0 — не проверять)     |
| `ALLOW_INSECURE_DEV`| —              | `1` отключает авторизацию для локальной разработки (не для прода) |

## API

Все эндпоинты (кроме `/healthz` и `/api/config`) требуют заголовок
`Authorization: tma <initData>`.

| Метод + путь              | Описание                          |
| ------------------------- | --------------------------------- |
| `GET /healthz`            | Проверка живости                  |
| `GET /api/config`         | Валюта и список категорий         |
| `GET /api/expenses`       | Список расходов пользователя      |
| `GET /api/summary`        | Итоги: сегодня, месяц, категории  |
| `POST /api/expenses`      | Добавить расход                   |
| `DELETE /api/expenses/:id`| Удалить расход                    |
